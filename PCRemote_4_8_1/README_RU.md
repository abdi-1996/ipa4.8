# PC Remote 4.8.1

**Clean Rebuild 4.8:** сеть и вход собраны заново вокруг `Network.framework`. Доступны **LAN / ZeroTier / Tailscale / Авто**, проверка связи до входа и автоматическая настройка Windows Firewall из окна сервера. Подробности: `NETWORK_4_8_RU.md`.

Версия сохраняет ComfyUI, CorelDRAW Remote, Проводник, удалённый экран, Wake-on-LAN, Пуск и остальные функции предыдущих сборок.

## Что изменилось

### Главный экран
- Только ярлыки, которые находятся на рабочем столе Windows, плюс программы, которые пользователь сам добавил из «Пуска».
- Строго **4 колонки × 6 рядов** на одной странице.
- Если ярлыков больше 24 — страницы переключаются свайпом влево/вправо.
- Вёрстка рассчитывается от реального размера экрана iPhone и не должна расширять экран по горизонтали.
- Настоящие иконки приложений извлекаются из Windows `.lnk/.exe`.

### «Пуск» как Windows 11
- Сверху строка поиска.
- Основной раздел — **«Недавние»**: программы, которые недавно запускались через PC Remote.
- Отдельная кнопка **«Все приложения»**.
- Системные инструменты Windows, PowerShell, Administrative Tools, службы, справка, деинсталляторы и другой служебный мусор фильтруются.
- Иконки выглядят так же, как на главном экране.
- Долгое нажатие/перетаскивание позволяет добавить программу на главный экран.
- Внизу «Пуска» есть меню питания: блокировка, сон, перезагрузка, выключение.

### Подключение
- На iPhone вводится **только ваш пароль**, который вы сами задаёте в PC Remote Server.
- LAN/ZeroTier/Tailscale/Auto и адреса доступны прямо на экране входа через кнопку «Подключение».
- В Auto приложение пробует **LAN → ZeroTier → Tailscale**.
- До входа можно нажать **«Проверить соединение»**: приложение проверит выбранный маршрут через безопасный `/api/ping`.
- После успешного входа сервер выдаёт отдельный API-токен; сам пароль не передаётся в каждом запросе.
- На Windows хранится только salted PBKDF2 verifier пароля. Смена пароля автоматически отзывает старые сессии.

### Wake-on-LAN
- Сохранённый ПК можно разбудить из контекстного меню устройства на экране входа.
- Wake-on-LAN также доступен в настройках.
- Работает, когда iPhone может отправить broadcast-пакет в домашнюю LAN. Через обычный Tailscale broadcast сам по себе не проходит — для удалённого WoL нужен relay в домашней сети.

### Удалённый экран
- Картинка ПК всегда вписывается в доступную область iPhone с сохранением пропорций.
- Координаты касания считаются относительно именно видимой картинки, поэтому края и чёрные поля не смещают нажатия.
- Используется **нативная Windows Touch Injection API**: свайпы передаются как настоящие сенсорные жесты Windows, а не как движение мыши.
- Тап — сенсорное нажатие.
- Удержание — длительное сенсорное нажатие Windows.
- Свайп — сенсорный свайп Windows.
- Если нативный touch API недоступен, сервер использует fallback.
- Режимы качества: **Качество / Баланс / Мин. задержка**.

### Клавиатура iPhone
- Отдельный экран клавиатуры убран.
- Стандартная клавиатура iOS появляется поверх удалённого экрана.
- Каждый символ сразу отправляется в активное поле Windows — без кнопки «Отправить».
- Backspace и Enter передаются сразу.
- Сервер использует Unicode `SendInput`, поэтому русский/английский текст не зависит от раскладки буфера обмена.
- После тапа приложение пытается определить через Windows UI Automation, является ли активный элемент текстовым полем; если да — клавиатура iPhone открывается автоматически.
- Клавиатуру можно открыть/скрыть вручную маленькой кнопкой, если приложение Windows не сообщает тип поля.

### Проводник и файлы
- Любой файл с ПК можно скачать и открыть на iPhone.
- Долгое нажатие на файл: **Открыть на iPhone / Сохранить в «Файлы» / Поделиться / Открыть на ПК**.
- В полноэкранном просмотре всегда есть «Назад», а также кнопки сохранения и Share Sheet.
- В любой папке ПК кнопка `+` открывает системный Files picker iPhone и загружает выбранные файлы обратно на ПК.
- Можно выбрать несколько файлов за один импорт.

### Темы
- Светлая, тёмная и автоматическая тема.
- Стили: Windows 11, Стекло, Графит, Аврора.
- Выбор сохраняется после перезапуска.

### ComfyUI 4.3 — Advanced + свободный редактор нод
- Большая кнопка **Workflow** с названием активной схемы находится сверху экрана ComfyUI.
- Библиотека: **Недавние / Избранные / Все**, импорт `+` с ПК или iPhone и кнопка **Изменить**.
- Главный экран больше не содержит отдельный блок Models. Любую настройку текущей ноды можно вынести в раскрывающийся **Advanced**.
- В `Advanced` по умолчанию ищутся Steps, Seed и Size; через `+ Добавить параметр` можно выбрать ноду и её настройку, переименовать пункт, переставить или убрать его.
- Positive Prompt получил **Templates** и `+` для собственных шаблонов. Профили WAN и Z-Image получают разную структуру подсказок; для остальных image/video workflow используется подходящий общий набор.
- Вместо технической строки CUDA показываются GPU, CPU, RAM и VRAM.
- Кнопка **Изменить** открывает свободный canvas: ноды можно размещать где угодно, менять размер и масштабировать полотно.
- Цветные светящиеся коннекторы создаются перетаскиванием от выхода к совместимому входу. Тап по занятому входу разрывает связь.
- В правом верхнем углу редактора `+` открывает поиск по реально установленным нодам ComfyUI, включая базовые Load Checkpoint, Load LoRA, Load Image, KSampler и другие.
- Двойной тап двумя пальцами — Undo, один тап тремя пальцами — Redo; кнопки ↶/↷ также доступны сверху.
- Кнопка расширения на ноде центрирует её настройки: название, цвет, Mute и реальные scalar-параметры из `/object_info`.
- Save-format JSON доступен для визуального редактирования; запуск через `/prompt` требует API-format workflow.

### Windows Server
- Питание: блокировка, сон, перезагрузка, выключение.
- Автозапуск после входа в Windows можно включить прямо из окна сервера.
- Также есть `INSTALL_AUTOSTART.bat` и `REMOVE_AUTOSTART.bat`.

## Важное ограничение: вход в Windows после перезагрузки

Обычная программа Windows **не может безопасно вводить пароль в защищённый экран входа Windows (Secure Desktop)**. Для настоящего удалённого ввода пароля до входа пользователя нужен отдельный нативный Windows **Credential Provider**, установленный с правами администратора и тщательно протестированный.

Поэтому PC Remote 4.3 **не передаёт и не сохраняет пароль Windows и не пытается обходить экран входа**. Автозапуск этой версии запускает сервер после входа пользователя в Windows.

Это ограничение оставлено намеренно, чтобы не хранить пароль Windows в небезопасном виде и не создавать компонент, который может заблокировать вход в систему.

## Установка Windows

### Из исходников
1. Установите Python 3.11+.
2. Откройте папку `windows`.
3. Запустите `RUN.bat`.
4. В Windows Firewall разрешите доступ только для частной сети.
5. Скопируйте ID из окна PC Remote Server.

### EXE
Запустите `BUILD_EXE.bat`. Готовый файл появится в `windows/dist/PCRemoteServer.exe`.

### Автозапуск
В окне сервера нажмите **«Включить автозапуск»**, либо используйте `INSTALL_AUTOSTART.bat`.

## Сборка IPA через GitHub Actions

Workflow уже лежит в `.github/workflows/main.yml` и **сам ищет `PCRemote.xcodeproj`**, поэтому при следующих обновлениях не нужно менять путь к проекту.

1. Загрузите содержимое проекта в GitHub.
2. Откройте **Actions → Build PC Remote → Run workflow**.
3. После успешной сборки скачайте artifact `PCRemote-IPA`.
4. Распакуйте artifact и установите `PCRemote.ipa` через Sideloadly поверх предыдущей версии.

## Безопасность
- Не публикуйте пароль подключения и не открывайте порт PC Remote напрямую в интернет.
- Не открывайте порт PC Remote напрямую в интернет.
- Для удалённого доступа используйте VPN/Tailscale.
- Команды питания требуют подтверждения в интерфейсе iPhone.

## PC Remote 4.3 — ComfyUI

Если ComfyUI работает на том же компьютере, PC Remote автоматически использует локальный адрес `127.0.0.1:8188` и открывает ComfyUI отдельным нативным экраном на iPhone.

В модуле доступны workflow, prompts, настраиваемый Advanced, model-aware Templates, свободный редактор нод, очередь, progress и результаты. Для подробностей смотрите `COMFYUI_RU.md`.


## Tailscale в версии 4.4

1. Установите Tailscale на Windows и iPhone и войдите в один tailnet.
2. Запустите новый PC Remote Server 4.4. В окне сервера появится Tailscale IP, если Tailscale подключён.
3. При локальном подключении приложение автоматически сохранит Tailscale IP из статуса сервера. Новый ID устройства также содержит Tailscale IP и MagicDNS.
4. На iPhone откройте Настройки → Подключение и выберите «Авто», «Tailscale» или «LAN». «Авто» сначала пробует Tailscale и затем LAN.
5. Для подключения вне дома Tailscale должен быть включён и на iPhone, и на Windows.

Wake-on-LAN при полностью выключенном ПК по-прежнему требует отдельного устройства в домашней сети, потому что Tailscale на выключенном ПК не работает.
