# ComfyUI в PC Remote 4.3

ComfyUI открывается как отдельный нативный экран iPhone и общается с локальным ComfyUI через PC Remote Server.

## Библиотека Workflow

Вверху главного экрана ComfyUI находится кнопка **Workflow** с названием активной схемы.

После нажатия открывается библиотека:
- **Недавние** — workflow из истории выполнений ComfyUI;
- **Избранные** — отмеченные звездой на iPhone;
- **Все** — импортированные workflow, сохранённые workflow ComfyUI и недавние схемы.

Кнопка **+**:
- **Импорт с ПК** — открывает проводник PC Remote и позволяет выбрать `.json`;
- **Импорт с iPhone** — открывает системный iOS Files picker.

PC Remote читает сохранённые JSON из user-data библиотеки ComfyUI. Несохранённая вкладка браузера, которой ещё нет в user-data/history, не может быть получена сервером — её нужно сохранить в ComfyUI или импортировать JSON.

## Форматы Workflow

ComfyUI использует два разных JSON-представления:
- обычный **save-format** — хранит визуальную схему, позиции, цвета и UI-данные;
- **API-format** — исполняемый граф `class_type + inputs`.

PC Remote 4.3 показывает и редактирует оба формата. Непосредственный Generate через локальный API доступен для API-format workflow и для workflow из history, где ComfyUI уже сохранил исполняемый prompt.

## Главный экран: Advanced и Templates

Отдельный блок **Models** убран. После Positive/Negative Prompt находится кнопка **Advanced**.

- Advanced можно свернуть/развернуть стрелкой.
- По умолчанию PC Remote пытается добавить Steps, Seed и Size.
- `+ Добавить параметр` показывает ноды текущего workflow, затем редактируемые параметры выбранной ноды.
- Параметр можно переименовать, поднять/опустить или убрать из Advanced, не удаляя его из workflow.
- Size поддерживает быстрые ratios 1:1, 4:3, 3:4, 16:9 и 9:16.
- Checkpoint, LoRA, VAE, sampler и любые другие параметры добавляются таким же способом.

Рядом с **Positive Prompt** находятся **Templates** и `+`.

- Templates добавляет готовый фрагмент в текущий prompt.
- Есть категории Кожа, Лицо, Тело, Детали, Освещение, Камера, Ракурс, Стиль, Экшен и Кинематика.
- Для WAN показываются video-oriented шаблоны сцены, движения и камеры.
- Для Z-Image показываются image/photoreal шаблоны деталей, света, камеры и композиции.
- `+` сохраняет текущий prompt как пользовательский шаблон.

## Свободный редактор нод

Нажмите **Изменить** у выбранного workflow.

- Редактор представляет собой большое свободное полотно, а не двухколоночный список.
- Ноду можно удержать и перетащить в любое место; маркер ↘ меняет её ширину и высоту.
- Pinch меняет масштаб canvas, прокрутка работает по горизонтали и вертикали.
- Коннекторы отображаются цветными светящимися кривыми по типам MODEL/CLIP/IMAGE/VAE/LATENT и т. д.
- Потяните от выходного кружка ноды к совместимому входу другой ноды, чтобы создать связь.
- Тап по уже подключённому входу отключает связь.
- Кнопка `+` в правом верхнем углу открывает Node Browser с поиском по `/object_info`. В начале списка — рекомендуемые базовые ноды; ввод `lo` фильтрует Load LoRA, Load Image и другие совпадения.
- Кнопка расширения на ноде открывает центрированный инспектор. Там можно переименовать ноду, выбрать цвет, включить Mute и изменить её реальные параметры.
- Двойной тап двумя пальцами выполняет Undo, один тап тремя пальцами — Redo. Те же действия доступны кнопками ↶/↷.

Структурное редактирование recent workflow из history ограничено: сначала сохраните/импортируйте workflow, чтобы добавлять и удалять ноды и менять связи.

## Подключение

По умолчанию Windows Server обращается к `http://127.0.0.1:8188`. iPhone напрямую порт 8188 не открывает: запросы идут через авторизованный PC Remote Server.
