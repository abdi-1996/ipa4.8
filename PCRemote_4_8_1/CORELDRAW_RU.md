# CorelDRAW внутри PC Remote 4.6.2

При нажатии CorelDRAW на домашнем экране PC Remote:

1. настоящий CorelDRAW запускается на Windows;
2. на iPhone открывается отдельный нативный iOS-интерфейс;
3. PC Remote управляет CorelDRAW через его COM/Object Model на том же ПК.

## Что доступно в 4.6

- живой предпросмотр активной страницы;
- pinch-to-zoom и перемещение предпросмотра;
- новый документ и открытие CDR/CDT/CMX/SVG/PDF/AI/EPS с ПК;
- список объектов активной страницы и выбор объекта;
- X/Y, ширина, высота, поворот;
- заливка, цвет и толщина контура;
- создание прямоугольника, эллипса, текста и линии;
- Duplicate / Delete / Group / Ungroup;
- порядок объектов вперед/назад;
- Undo / Redo;
- Select All;
- страницы: предыдущая, следующая, новая, переход по номеру;
- Save;
- кнопка показа полного CorelDRAW на ПК для функций, которые пока не вынесены в мобильную панель.

## Важно

Модуль не заменяет весь интерфейс CorelDRAW один-в-один. Он дает нативный мобильный слой для самых частых операций, а сложные специализированные диалоги и сторонние плагины остаются доступны через полный CorelDRAW/удаленный экран.
