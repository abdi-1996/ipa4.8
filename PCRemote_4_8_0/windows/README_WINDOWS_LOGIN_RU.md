# Вход в Windows после перезагрузки

PC Remote 4.3 не вводит пароль Windows в экран Secure Desktop.

Причина: экран входа Windows работает в защищённой системной среде. Обычная программа пользователя, PyAutoGUI, SendInput и Touch Injection не имеют права безопасно управлять этим экраном.

Для настоящего удалённого входа по паролю нужен отдельный нативный Windows Credential Provider (COM DLL), устанавливаемый с правами администратора. Такой компонент должен проходить отдельное тестирование, потому что ошибка в Credential Provider может лишить пользователя возможности войти в Windows.

Автозапуск PC Remote 4.3 запускает сервер после входа пользователя в Windows.
