# Проверка сети PC Remote 4.8

1. Запустите `PCRemoteServer.exe`.
2. Убедитесь, что в окне сервера указан нужный LAN / ZeroTier / Tailscale IP.
3. Один раз нажмите **«Настроить LAN / Tailscale / ZeroTier»** и подтвердите UAC.
4. На iPhone откройте **Подключение** до входа, выберите маршрут и нажмите **«Проверить соединение»**.
5. При успешной проверке приложение покажет имя ПК, маршрут и версию сервера.
6. Затем введите пароль и нажмите **«Войти»**.
